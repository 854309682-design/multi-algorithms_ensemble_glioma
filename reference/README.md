# reference/ — small reference inputs shipped with the repository

These are the only analysis inputs committed here; everything else is downloaded (see
`data_acquisition/README.md`) or generated by the pipeline (`results/`).

## `protein_coding_genes.txt`

One gene symbol per line (19,938 symbols), used as the **protein-coding whitelist** that refines the
NMF/TAM candidate set into the frozen signature. Read by:

- `code/03_modeling/05_signature_proteincoding.R` (primary signature)
- `code/03_modeling/08_sensitivity.R` (λ.min / λ.1se and GBM-only variants)
- `code/04_validation/08_tcga_holdout.R` (repeated hold-out)

The whitelist was defined on the gene annotation that accompanies the TCGA training matrix
(`docs/PIPELINE.md` §2) and is shipped so that the candidate-set definition stays reproducible even
if the annotation file upstream changes.

## `published_signatures/` (empty in the repository, generated on demand)

`code/04_validation/07a_gmt_to_signature_tsv.py` and `07c_cgp_published_signatures.py` read the
MSigDB `v2026.1.Hs` GMTs and write one `SYMBOL<tab>weight` table per gene set / published signature
into this directory. Download the GMTs from
<https://data.broadinstitute.org/gsea-msigdb/msigdb/release/2026.1.Hs/> into this folder first
(`h.all.*.symbols.gmt`, `c2.cp.*.symbols.gmt`, `c2.cgp.*.symbols.gmt`), then run:

```bash
python code/04_validation/07a_gmt_to_signature_tsv.py
python code/04_validation/07c_cgp_published_signatures.py
```

Only the resulting `*.tsv` tables are consumed downstream (`07_published_signature_comparison.R`,
`07b_signature_inflation_benchmark.R`), so the GMTs themselves stay out of version control.
